# UniMate releases

Binary installers for 牛小匠 UniMate by JR Academy. Application source is maintained separately in a private repository.

Downloads: [Releases](https://github.com/JR-Academy-AI/unimate-releases/releases).

Version 0.1.0 is a macOS Apple Silicon prerelease. Its application and DMG are Developer ID signed, Apple notarized, and stapled. Automatic updates are not enabled in this build. Windows and Intel Mac installers are not included.

Release assets are limited to installers, packaged applications, and checksums. This repository must never contain application source, credentials, signing keys, or build logs.
